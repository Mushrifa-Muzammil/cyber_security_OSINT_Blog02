## 📖 About The Project

This is an **interactive educational blog post** covering the top 10 Open Source Intelligence (OSINT) tools used by cybersecurity professionals and investigators worldwide. Unlike a static blog, this version includes:

- **Dynamic tool filtering** by category (Reconnaissance, Analysis, Social Media, Search Engines)
- **Interactive tool cards** with hover effects and click highlighting
- **Responsive grid layout** that adapts to all screen sizes
- **Visual gallery** showing OSINT in action
- **Unique advantages section** highlighting key OSINT benefits

The content is designed to educate security professionals, ethical hackers, and investigators on how to gather intelligence from publicly available sources ethically and effectively.
